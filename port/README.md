# 分阶段开发配方

这里保留移植过程中用于构建、变换源码和封装的原始脚本。文件名中的数字为实验阶段，不是安装步骤。

- 最终入口见[构建指南](../docs/BUILD.zh-CN.md)。
- 最终运行文本配置见`packaging/device-support/tree/`。
- 实际外置模块源码见`snapshots/`，主内核修改见`kernel/patches/`。
- 这里的脚本可能读取未发布的`out/`中间产物、固件或私有settings归档，不保证在空目录直接逐项运行。
- 单机序列号、网络名称和构建机地址已去除或替换为占位符。使用可配置的`switch/`入口生成自己的模块。

较早的失败实验与最终实现都用于溯源；例如`refresh-live75`不能代替最终76版，麦克风72和73有不同的职责。不要根据脚本名猜测一个“最大的版本号”就覆盖整个运行栈。
